# Git & GitHub Workflow Notes

## Git

Git is a distributed version control system used to track changes in a project.

## GitHub

GitHub is a platform for hosting Git repositories and collaborating with other developers.

## Basic Workflow

1. Create or modify files.
2. Check changes with `git status`.
3. Add changes with `git add`.
4. Create a commit with `git commit`.
5. Push changes to GitHub with `git push`.
6. Use branches for feature work.
7. Open a Pull Request to merge changes.

## Branching

Feature branches allow developers to work on changes separately from the main branch.

Example:

```bash
git switch -c feature/example
