# Git & GitHub Capstone

## Project Description

This project is a practical Git and GitHub workflow demonstration created for the Git & GitHub Bootcamp Capstone.

The project demonstrates how to use Git and GitHub in a real development workflow, including commits, branches, pull requests, issues, code review, and GitHub Actions.

## Features

- Git repository initialization
- Meaningful Git commits
- Feature branches
- Pull requests
- GitHub Issues
- Code review
- GitHub Actions automation

## How to Run

This project is mainly designed to demonstrate Git and GitHub workflow practices.

Clone the repository and open the project folder:

```bash
git clone <repository-url>
cd git-github-capstone
